1 Data sets, input matrices and outcome vectors

DefDefinition 1 (Data set)

Definition 1 (Data set) A data set is a finite collection of \(n\) labelled observations, that is, \(n\) pairs \((\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_i, y_i)\), where \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_i\) is an input vector and \(y_i\) is the corresponding outcome:

\[ \mathcal{D}\stackrel{\text{def}}{=}\mathopen{}\left\{(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_i, y_i) : i = 1, \ldots, n\right\}\mathclose{} . \tag{1}\]

RemarkRemark 1 (The sets we split a data set into)

Remark 1 (The sets we split a data set into). We divide a data set into subsets, each with its own job. “Set” in the names training set, validation set and test set is short for “subset of the data set”. A training/validation/test split assigns each observation to one of them, and the training set is the subset a fitting procedure is applied to.

DefDefinition 2 (Input matrix)

Definition 2 (Input matrix) The input matrix \(\mathbf{X}\) of a data set \(\mathcal{D}\) stacks the \(n\) inputs \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_i\) as rows, with one column for each of the \(p\) input variables:

\[ \mathbf{X}= \begin{bmatrix} {\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_1}^{\top} \\ \vdots \\ {\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_{n}}^{\top} \end{bmatrix} . \tag{2}\]

DefDefinition 3 (Outcome vector)

Definition 3 (Outcome vector) The outcome vector \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{y}}\vphantom{y}}\) of a data set \(\mathcal{D}\) stacks its \(n\) outcomes \(y_i\):

\[ \mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{y}}\vphantom{y}}= \begin{bmatrix} y_1 \\ \vdots \\ y_{n} \end{bmatrix} . \tag{3}\]

ExmExample 1 (The input matrix and outcome vector of the first five cars)

Example 1 (The input matrix and outcome vector of the first five cars) In the mtcars data frame, take the fuel economy mpg as the outcome \(y\) and the gross horsepower hp and weight wt as the \(p= 2\) inputs. The first five cars give a data set of \(n= 5\) observations.

# take the first five cars from the mtcars data frame
cars5 <- head(mtcars, 5)

# stack the two inputs as columns, one row per car
X_cars5 <- as.matrix(cars5[, c("hp", "wt")])

# stack the outcomes into one vector
y_cars5 <- cars5$mpg

# show the input matrix and the outcome vector side by side
cbind(X_cars5, mpg = y_cars5)
#>                    hp    wt  mpg
#> Mazda RX4         110 2.620 21.0
#> Mazda RX4 Wag     110 2.875 21.0
#> Datsun 710         93 2.320 22.8
#> Hornet 4 Drive    110 3.215 21.4
#> Hornet Sportabout 175 3.440 18.7

The input matrix X_cars5 has 5 rows, one per car, and 2 columns, one per input variable. The outcome vector y_cars5 has 5 entries, one per car.

2 Fitting and scoring prediction rules

DefDefinition 4 (Covariate)

Definition 4 (Covariate) A covariate \(x\) is a variable whose value is used to predict the outcome \(y\).

ExmExample 2 (A car’s weight)

Example 2 (A car’s weight) To predict a car’s fuel economy \(y\), the car’s weight is a covariate \(x\).

DefDefinition 5 (Mean function)

Definition 5 (Mean function) The mean function \(\mu\) of an outcome \(Y\) given a covariate \(X\) maps each covariate value \(x\) to the mean of \(Y\) given \(X= x\):

\[ \mu\mathopen{}\left(x\right)\mathclose{} \stackrel{\text{def}}{=}\operatorname{E}\mathopen{}\left[Y\mid X= x\right]\mathclose{}. \tag{4}\]

DefDefinition 6 (Mean-function model family)

Definition 6 (Mean-function model family) A mean-function model family \(\mathcal{H}\) is a set of functions, each of which maps a covariate value \(x\) to a candidate for the value \(\mu\mathopen{}\left(x\right)\mathclose{}\) of the mean function at \(x\).

ExmExample 3 (Polynomials of degree at most \(d\))

Example 3 (Polynomials of degree at most \(d\)) The polynomials of degree at most \(d\) form a mean-function model family \(\mathcal{H}\): each polynomial maps a covariate value \(x\) to a candidate for the value of the mean function at \(x\), and the members differ in their coefficients.

DefDefinition 7 (Objective function)

Definition 7 (Objective function) An objective function \(\mathcal{J}\) is a rule that gives each member \(h\) of a model family \(\mathcal{H}\) a number computed from a data set \(\mathcal{D}\), where a smaller number means a better fit to the data:

\[ h\mapsto {\mathcal{J}\mathopen{}\left(h; \mathcal{D}\right)\mathclose{}}, \quad h\in \mathcal{H}. \tag{5}\]

ExmExample 4 (Residual sum of squares)

Example 4 (Residual sum of squares) For the polynomials \(h\) in Example 3, the residual sum of squares is an objective function \(\mathcal{J}\): it gives each polynomial the sum over the observations of its squared difference from the observed outcome.

DefDefinition 8 (Optimization algorithm)

Definition 8 (Optimization algorithm) An optimization algorithm \(\mathcal{A}\) is a step-by-step procedure that searches a model family \(\mathcal{H}\) for a member \(h\) with a small value of an objective function \(\mathcal{J}\):

\[ h= \mathcal{A}\mathopen{}\left(\mathcal{H}, \mathcal{J}, \mathcal{D}\right)\mathclose{} \in \mathcal{H}. \tag{6}\]

ExmExample 5 (Exact and exhaustive searches)

Example 5 (Exact and exhaustive searches) For the residual sum of squares over the polynomials in Example 4, solving the normal equations is an optimization algorithm \(\mathcal{A}\) that finds the unique minimizer in one step.

Trying every member of a finite model family and keeping the one with the smallest value of the objective function is another, and it ends after the last member.

DefDefinition 9 (Random seed)

Definition 9 (Random seed) A random seed \(\mathfrak{s}\) is a number that fixes the sequence of random numbers a computer generates: the same seed gives the same sequence.

Source: Wikipedia contributors [1].

ExmExample 6 (Reproducing a random split)

Example 6 (Reproducing a random split) Randomly splitting a data set in half twice with the same random seed \(\mathfrak{s}\) gives the same two halves. Splitting it with two different seeds gives two different splits.

DefDefinition 10 (Preprocessing)

Definition 10 (Preprocessing) The preprocessing \(\phi\) of a fitting procedure is the map from covariate values \(x\) to the features \(\phi\mathopen{}\left(x\right)\mathclose{}\) that the procedure’s model family uses as inputs.

ExmExample 7 (Standardizing a covariate)

Example 7 (Standardizing a covariate) Standardization is a preprocessing \(\phi\): it maps each covariate value \(x\) to its standardized value.

DefDefinition 11 (Fitted model)

Definition 11 (Fitted model) A fitted model \(\hat{h}\) is a member of a model family \(\mathcal{H}\) that has been chosen to describe a data set \(\mathcal{D}\).

ExmExample 8 (A fitted line)

Example 8 (A fitted line) A line chosen to describe the weights and fuel economies of the cars in the mtcars data set \(\mathcal{D}\) is a fitted model \(\hat{h}\).

DefDefinition 12 (Fitting procedure)

Definition 12 (Fitting procedure) A fitting procedure \(g\) is a function that, given any data set \(\mathcal{D}\), produces the fitted model \(\hat{h}= g\mathopen{}\left(\mathcal{D}\right)\mathclose{}\):

\[ \mathcal{D} \mapsto \hat{h} = g\mathopen{}\left(\mathcal{D}\right)\mathclose{}. \tag{7}\]

A fitting procedure is specified by these inputs:

  • model family \(\mathcal{H}\);
  • objective function \(\mathcal{J}\);
  • optimization algorithm \(\mathcal{A}\);
  • random seed \(\mathfrak{s}\);
  • tuning parameters \(\lambda\);
  • preprocessing \(\phi\).
ExmExample 9 (Inputs of least-squares polynomial fitting)

Example 9 (Inputs of least-squares polynomial fitting) The least-squares fitting procedure \(g\) for polynomials of degree \(d\) is specified by these inputs:

  • model family \(\mathcal{H}\): the polynomials of degree at most \(d\);
  • objective function \(\mathcal{J}\): the residual sum of squares;
  • optimization algorithm \(\mathcal{A}\): solving the normal equations;
  • random seed \(\mathfrak{s}\): none, since nothing is random;
  • tuning parameter \(\lambda\): the degree \(d\);
  • preprocessing \(\phi\): none.
DefDefinition 13 (Training set)

Definition 13 (Training set) A training set is the data to which a fitting procedure is applied: \(n\) observations, written as an ordered list indexed by a set \(I\) of \(n\) observation numbers:

\[ \mathcal{D}_{\text{train}}\stackrel{\text{def}}{=}\mathopen{}\left((\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_{i}, y_{i})\right)\mathclose{}_{i\in I}, \quad \mathopen{}\left|I\right|\mathclose{} = n. \tag{8}\]

Source: Wikipedia contributors [2].

RemarkRemark 2 (Source: Training set)

Remark 2 (Source: Training set). Hastie et al. [3, Sec. 7.2], who also write the training set as \(\mathcal{T}\).

DefDefinition 14 (Prediction rule)

Definition 14 (Prediction rule) The prediction rule \(\hat y\) is shorthand for the fitted model \({\hat y_{\mathcal{D}_{\text{train}}}}\) that a fitting procedure \(g\) produces from the training set \(\mathcal{D}_{\text{train}}\), written without the subscript when the training set is the one in use:

\[ \hat y\stackrel{\text{def}}{=}{\hat y_{\mathcal{D}_{\text{train}}}}. \tag{9}\]

DefDefinition 15 (Prediction function family (hypothesis class, hypothesis space))

Definition 15 (Prediction function family (hypothesis class, hypothesis space)) A prediction function family \(\mathcal{Y}\) (also called a hypothesis class or a hypothesis space) is a set of functions, each of which maps a covariate value \(x\) to a prediction of the outcome.

ExmExample 10 (Polynomials as prediction functions)

Example 10 (Polynomials as prediction functions) Predicting the outcome at a covariate value \(x\) by the value at \(x\) of a polynomial of degree at most \(d\) makes the polynomials of Example 3 a prediction function family \(\mathcal{Y}\). The same functions are the members of a mean-function model family \(\mathcal{H}\) when each one is a candidate for the mean function, and the members of \(\mathcal{Y}\) when each one is a candidate for how to predict.

DefDefinition 16 (New observation)

Definition 16 (New observation) A new observation \((X_{*}, Y_{*})\) relative to a training set \(\mathcal{D}_{\text{train}}\) is a covariate value and an outcome drawn from the same population as the observations of \(\mathcal{D}_{\text{train}}\), and statistically independent of \(\mathcal{D}_{\text{train}}\). The subscript \(*\) marks a quantity of the new observation, as in \(X_{*}\) and \(Y_{*}\), and distinguishes it from the indexed observations \((\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_{i}, y_{i})\) of \(\mathcal{D}_{\text{train}}\). It is the new observation of the pds notes, where the data used to choose the prediction function is \(\mathcal{D}_{\text{train}}\), to which a fitting procedure is applied.

ExmExample 11 (A new observation for the first five cars)

Example 11 (A new observation for the first five cars) Take the first five cars of mtcars as the training set, with the gross horsepower hp and weight wt as the covariate values and the fuel economy mpg as the outcome, as in Example 1. Treat the sixth car as a new observation: a car from the same population that was not used to form the training set.

# the sixth car is not among the five training cars
new_car <- mtcars |>
  dplyr::slice(6) |>
  dplyr::select(hp, wt, mpg)
new_car

Its covariate value is \(X_{*}= (105, 3.46)\) and its outcome is \(Y_{*}= 18.1\).

DefDefinition 17 (Noise)

Definition 17 (Noise) The noise \(\nu\) of a new observation \(\mathopen{}\left(X_{*}, Y_{*}\right)\mathclose{}\) at the covariate value \(X_{*}= x\) is the deviation of the new outcome \(Y_{*}\) from the mean function value \(\mu\mathopen{}\left(x\right)\mathclose{}\):

\[ \nu\stackrel{\text{def}}{=}Y_{*}- \mu\mathopen{}\left(x\right)\mathclose{}. \tag{10}\]

ExmExample 12 (The noise of one new outcome)

Example 12 (The noise of one new outcome) Suppose the mean function value at \(x\) is \(\mu\mathopen{}\left(x\right)\mathclose{} = 5\). A new outcome \(Y_{*}= 5.3\) at \(x\) has noise \(\nu= 5.3 - 5 = 0.3\). A new outcome \(Y_{*}= 4.6\) at \(x\) has noise \(\nu= 4.6 - 5 = -0.4\).

LemTheorem 1 (The noise has population mean zero)

Theorem 1 (The noise has population mean zero) Given \(X_{*}= x\), the noise \(\nu\) has population mean \(0\):

\[ \operatorname{E}\mathopen{}\left[\nu\mid X_{*}= x\right]\mathclose{} = 0. \tag{11}\]

ProofProof

Proof. Take every expectation to be conditional on \(X_{*}= x\). The value \(\mu\mathopen{}\left(x\right)\mathclose{}\) is a constant given \(X_{*}= x\).

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[\nu\right]\mathclose{} &= \operatorname{E}\mathopen{}\left[Y_{*}- \mu\mathopen{}\left(x\right)\mathclose{}\right]\mathclose{} && \text{(definition of the noise)} \\ &= \operatorname{E}\mathopen{}\left[Y_{*}\right]\mathclose{} - \mu\mathopen{}\left(x\right)\mathclose{} && \text{(linearity of expectation; a constant is its own mean)} \\ &= \mu\mathopen{}\left(x\right)\mathclose{} - \mu\mathopen{}\left(x\right)\mathclose{} && \text{(definition of the mean function)} \\ &= 0 && \text{(} a - a = 0 \text{)} \end{aligned} \]

ExmExample 13 (A new outcome that is 4 or 6 with equal probability)

Example 13 (A new outcome that is 4 or 6 with equal probability) Suppose a new outcome at \(x\) is \(4\) or \(6\), each with probability \(1/2\). Its population mean is \(\mu\mathopen{}\left(x\right)\mathclose{} = 5\), so its noise is \(-1\) or \(+1\), each with probability \(1/2\). The population mean of the noise is \(\mathopen{}\left(-1\right)\mathclose{} \cdot \frac{1}{2} + 1 \cdot \frac{1}{2} = 0\), as Theorem 1 says.

DefDefinition 18 (Loss of a prediction rule on an observation)

Definition 18 (Loss of a prediction rule on an observation) The loss of a prediction rule \(\hat y\) on an observation \((x_{i}, y_{i})\) is the cost, under a loss function \(L\), of its prediction \({\hat y\mathopen{}\left(x_{i}\right)\mathclose{}}\) of the outcome \(y_{i}\):

\[ \ell_{i}\mathopen{}\left(\hat y\right)\mathclose{} \stackrel{\text{def}}{=}L\mathopen{}\left(y_{i}, {\hat y\mathopen{}\left(x_{i}\right)\mathclose{}}\right)\mathclose{}. \tag{12}\]

The subscript names the observation, a member of a family of losses, and the parentheses hold the prediction rule the loss is evaluated at. The index \(*\) names the new observation \((X_{*}, Y_{*})\), so \(\ell_{*}\mathopen{}\left(\hat y\right)\mathclose{} = L\mathopen{}\left(Y_{*}, {\hat y\mathopen{}\left(X_{*}\right)\mathclose{}}\right)\mathclose{}\). When the rule is clear from context, we write \(\ell_{i}\) for \(\ell_{i}\mathopen{}\left(\hat y\right)\mathclose{}\).

RemarkRemark 3 (Squared-error loss)

Remark 3 (Squared-error loss). Each error defined below holds for any loss. The examples, exercises and the bias-variance decomposition use squared-error loss, \(L\mathopen{}\left(y, \hat{y}\right)\mathclose{} = {\mathopen{}\left(\hat{y} - y\right)\mathclose{}}^2\), unless they say otherwise. Then the loss on an observation is the square of its prediction error, \(\ell_{i} = \varepsilon_{i}^2\), and each average loss below is a sample mean squared error.

DefDefinition 19 (Generalization error)

Definition 19 (Generalization error) The generalization error of a prediction rule \(\hat y\) fitted to a training set \(\mathcal{D}_{\text{train}}\) is its expected loss \(\ell_{*}\) on a new observation \((X_{*}, Y_{*})\), with \(\mathcal{D}_{\text{train}}\) held fixed [4]:

\[ \operatorname{Err}_{\mathcal{D}_{\text{train}}} \stackrel{\text{def}}{=}\operatorname{E}\mathopen{}\left[\ell_{*} \mid \mathcal{D}_{\text{train}}\right]\mathclose{}. \tag{13}\]

Source: Wikipedia contributors [4].

RemarkRemark 4 (Source: Generalization error)

Remark 4 (Source: Generalization error). The risk form follows Brian Hutchinson’s Fall 2025 lecture notes; the conditional form, with the training set held fixed, follows Hastie et al. [3, Sec. 7.2].

DefDefinition 20 (Held-out set (hold-out set))

Definition 20 (Held-out set (hold-out set)) A held-out set for a training set \(\mathcal{D}_{\text{train}}\) is a list of \(m\) further observations, none of them in \(\mathcal{D}_{\text{train}}\), that the fitting procedure does not use and on which the prediction rule \(\hat y\) is scored:

\[ \mathopen{}\left((x_{*,1}, y_{*,1}), \ldots, (x_{*,m}, y_{*,m})\right)\mathclose{}. \tag{14}\]

RemarkRemark 5 (Source: Held-out set (hold-out set))

Remark 5 (Source: Held-out set (hold-out set)). Also called a hold-out set [5, Sec. 5.1.1].

DefDefinition 21 (Root mean squared error of predictions)

Definition 21 (Root mean squared error of predictions) The sample root mean squared error (sRMSE) of predictions, also called their root mean squared error, \(\hat y_1, \ldots, \hat y_n\) of observed outcomes \(y_1, \ldots, y_n\) is the square root of their sMSE:

\[ \operatorname{sRMSE}\mathopen{}\left(\hat y\right)\mathclose{} \stackrel{\text{def}}{=}\sqrt{\operatorname{sMSE}\mathopen{}\left(\hat y\right)\mathclose{}}. \tag{15}\]

DefDefinition 22 (Training error)

Definition 22 (Training error) The training error of a prediction rule \(\hat y\) fitted to a training set \(\mathcal{D}_{\text{train}}\) is its sample mean loss \(\ell_{i}\) on the training observations \(i\in I\):

\[ \overline{\operatorname{err}}\stackrel{\text{def}}{=}\frac{1}{n}\sum_{i=1}^n\ell_{i}. \tag{16}\]

RemarkRemark 6 (Source: Training error)

Remark 6 (Source: Training error). Hastie et al. [3, Sec. 7.2], who write the training error as \(\overline{\text{err}}\) and define it for any loss.

3 Overfitting

ExrExercise 1 (Training error versus error on new cars)

Exercise 1 (Training error versus error on new cars) The built-in mtcars data frame has \(n= 32\) cars. Fit four models for fuel efficiency mpg as a polynomial in weight wt, of degree 1, 2, 3, and 4, using only the first 20 rows as the training set. For each model, compute the sRMSE of its predictions on the 20 training rows and on the remaining 12 rows, a held-out set.

  1. Which degree has the smallest training sRMSE?
  2. Which degree has the smallest sRMSE on the 12 held-out rows?
  3. Do the terms added beyond degree 2 improve predictions for the held-out cars?
SolutionSolution 1

Solution 1. 

train_cars <- mtcars[1:20, ]
held_out_cars <- mtcars[21:32, ]

prediction_mse <- function(model, data) {
  response_only <- stats::update(stats::formula(model), . ~ 1)
  y <- stats::model.response(stats::model.frame(response_only, data))
  mean((predict(model, newdata = data) - y)^2)
}

rmse <- function(model, data) {
  sqrt(prediction_mse(model, data))
}

overfitting_results <- tibble::tibble(degree = 1:4) |>
  dplyr::mutate(
    fit = purrr::map(
      degree,
      \(d) lm(mpg ~ poly(wt, d, raw = TRUE), data = train_cars)
    ),
    training_RMSE = purrr::map_dbl(fit, rmse, data = train_cars),
    held_out_RMSE = purrr::map_dbl(fit, rmse, data = held_out_cars)
  ) |>
  dplyr::select(-fit)

overfitting_results
Show R code
best_train <- overfitting_results$degree[
  which.min(overfitting_results$training_RMSE)
]
best_held_out <- overfitting_results$degree[
  which.min(overfitting_results$held_out_RMSE)
]

c(best_train = best_train, best_held_out = best_held_out)
#>    best_train best_held_out 
#>             4             2

  1. The smallest training sRMSE is at degree 4. Each model contains the previous one as a special case, so its training sRMSE cannot increase as the degree grows.

  2. The smallest held-out sRMSE is at degree 2.

  3. No. Going from degree 2 to degree 3 or 4 lowers the training sRMSE a little but leaves the held-out sRMSE essentially unchanged (it does not fall below its degree-2 value). The terms beyond degree 2 improve the fit to the 20 training cars without improving predictions for the 12 held-out cars. Degree 1 to degree 2 is different: there the held-out sRMSE also falls.

DefDefinition 23 (Overfitting)

Definition 23 (Overfitting) Overfitting occurs when a prediction rule fits its training set well but predicts poorly for new observations [6].

Source: Wikipedia contributors [6].

ExmExample 14 (Overfitting in polynomial fits to cars)

Example 14 (Overfitting in polynomial fits to cars) In Exercise 1, the terms beyond degree 2 fit the 20 training cars more closely but do not predict the 12 held-out cars better. The effect is small here: it is the beginning of overfitting, not a dramatic case.

4 Generalization error

ExrExercise 2 (Score a fitted model on a car it has not seen)

Exercise 2 (Score a fitted model on a car it has not seen) A prediction rule \(\hat y\) has been fitted to a training set \(\mathcal{D}_{\text{train}}\) of \(n\) observations, such as the 20 training cars of Exercise 1. A new car \((X_{*}, Y_{*})\) is then drawn from the same population, independently of \(\mathcal{D}_{\text{train}}\).

  1. Holding \(\mathcal{D}_{\text{train}}\) fixed, write the average loss \(\ell_{*}\) that \(\hat y\) would incur over all such new cars, as an expectation. Then write it for squared-error loss, as the average squared prediction error.
  2. Which parts of your expression do you know, and which do you not know?
  3. The training sRMSE of Exercise 1 is the square root of the training error \(\overline{\operatorname{err}}\) under squared-error loss. What does \(\overline{\operatorname{err}}\) use in place of your expectation?
SolutionSolution 2

Solution 2.

  1. Average the loss over the distribution of \((X_{*}, Y_{*})\), with \(\mathcal{D}_{\text{train}}\), and so the rule \(\hat y\), held fixed:

    \[\operatorname{E}\mathopen{}\left[\ell_{*} \mid \mathcal{D}_{\text{train}}\right]\mathclose{}.\]

    For squared-error loss, the loss is the squared prediction error:

    \[\operatorname{E}\mathopen{}\left[\varepsilon_{*}^2 \mid \mathcal{D}_{\text{train}}\right]\mathclose{}.\]

  2. The rule \(\hat y\) is known, because we fitted it. The joint distribution of \((X_{*}, Y_{*})\) is unknown, so the expectation cannot be computed. If we knew that distribution, we would not need data to build a prediction rule.

  3. The training error \(\overline{\operatorname{err}}\) replaces the expectation over new cars with an average over the \(n\) training cars. Those cars are draws from the same population, but they are not independent of \(\mathcal{D}_{\text{train}}\): they are \(\mathcal{D}_{\text{train}}\), and \(\hat y\) was chosen to fit them.

DefDefinition 24 (Expected generalization error (expected prediction error, expected test error))

Definition 24 (Expected generalization error (expected prediction error, expected test error)) The expected generalization error of a fitting procedure \(g\) at training-set size \(n\) is the mean, over training sets \(\mathcal{D}_{\text{train}}\) of \(n\) observations drawn independently from the population, of the generalization error of the prediction rule that \(g\) produces from \(\mathcal{D}_{\text{train}}\):

\[ \operatorname{Err}^{g}\mathopen{}\left(n\right)\mathclose{} \stackrel{\text{def}}{=}\operatorname{E}\mathopen{}\left[\operatorname{Err}_{\mathcal{D}_{\text{train}}}\right]\mathclose{}, \quad \mathcal{D}_{\text{train}}= \mathopen{}\left((X_{i}, Y_{i})\right)\mathclose{}_{i\in I}, \quad \mathopen{}\left|I\right|\mathclose{} = n. \tag{17}\]

RemarkRemark 7 (Source: Expected generalization error (expected prediction error, expected test error))

Remark 7 (Source: Expected generalization error (expected prediction error, expected test error)). Also called the expected prediction error or expected test error [3, Sec. 7.2]. Hastie et al. write the quantity as \(\operatorname{Err}\), without the argument \(n\).

DefDefinition 28 (Distribution model)

Definition 25 (Distribution model) A distribution model \(P\) for an outcome \(Y\) given a covariate \(X\) gives each covariate value \(x\) a probability distribution for \(Y\) given \(X= x\), specified by its cumulative distribution function. The mean function \(\mu_{P}\) of \(P\) maps each covariate value \(x\) to the mean of that distribution:

\[ {\mu_{P}\mathopen{}\left(x\right)\mathclose{}} \stackrel{\text{def}}{=}\operatorname{E}_{P}\mathopen{}\left[Y\mid X= x\right]\mathclose{}. \tag{18}\]

DefDefinition 31 (Expected prediction loss at a covariate value)

Definition 31 (Expected prediction loss at a covariate value) The expected prediction loss at \(x\) of a fitting procedure \(g\) at training-set size \(n\) is the expected loss \(\ell_{*}\mathopen{}\left(\hat y\right)\mathclose{}\) of the prediction rule \(\hat y= {\hat y_{\mathcal{D}_{\text{train}}}}\) that \(g\) produces from \(\mathcal{D}_{\text{train}}\), on a new outcome \(Y_{*}\) with \(X_{*}= x\), averaged over random training sets \(\mathcal{D}_{\text{train}}\) of \(n\) observations drawn independently of \((X_{*}, Y_{*})\), and over \(Y_{*}\). \[ \operatorname{EPL}^{g}_{n}\mathopen{}\left(x\right)\mathclose{} \stackrel{\text{def}}{=}\operatorname{E}\mathopen{}\left[\ell_{*}\mathopen{}\left({\hat y_{\mathcal{D}_{\text{train}}}}\right)\mathclose{} \mid X_{*}= x\right]\mathclose{}. \tag{26}\]

RemarkRemark 8 (The expected prediction loss and the generalization error)

Remark 8 (The expected prediction loss and the generalization error). The generalization error \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\) holds the training set fixed and averages the loss over new covariate values too. The expected prediction loss at \(x\) averages over training sets as well, and holds the covariate value fixed. Neither is the test error: the test error is an average over a finite test set, so it estimates the generalization error without equalling it.

DefDefinition 32 (Expected prediction error at a covariate value)

Definition 32 (Expected prediction error at a covariate value) The expected prediction error at \(x\) (EPE; also the expected squared prediction error, ESPE) of a fitting procedure \(g\) at training-set size \(n\) is its expected prediction loss under squared-error loss, the expected value of the squared prediction error \(\varepsilon_{*}\mathopen{}\left(\hat y\right)\mathclose{} = {\hat y\mathopen{}\left(X_{*}\right)\mathclose{}} - Y_{*}\) of the prediction rule \(\hat y= {\hat y_{\mathcal{D}_{\text{train}}}}\) that \(g\) produces from \(\mathcal{D}_{\text{train}}\):

\[ \operatorname{EPE}^{g}_{n}\mathopen{}\left(x\right)\mathclose{} \stackrel{\text{def}}{=}\operatorname{E}\mathopen{}\left[\varepsilon_{*}\mathopen{}\left({\hat y_{\mathcal{D}_{\text{train}}}}\right)\mathclose{}^2 \mid X_{*}= x\right]\mathclose{}. \tag{27}\]

RemarkRemark 9 (The expected prediction error is a population mean squared error)

Remark 9 (The expected prediction error is a population mean squared error). The expected prediction error is the pMSE of the prediction \({\hat y\mathopen{}\left(x\right)\mathclose{}}\) as a prediction of the new outcome \(Y_{*}\). With squared-error loss, \(\operatorname{EPL}^{g}_{n}\mathopen{}\left(x\right)\mathclose{} = \operatorname{EPE}^{g}_{n}\mathopen{}\left(x\right)\mathclose{}\).

It differs from the pMSE of the same prediction as an estimator of the mean function value \(\mu\mathopen{}\left(x\right)\mathclose{}\): Theorem 4 shows that it exceeds that pMSE by the noise variance. The acronym omits “squared” because “error” already means squared error here. Another loss gives an expected prediction loss, not an EPE.

A prediction \({\hat y\mathopen{}\left(x\right)\mathclose{}}\) at \(x\) has squared bias \({\mathopen{}\left(\operatorname{Bias}\mathopen{}\left({\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}\right)\mathclose{}}^2 = 1\) and variance \(\operatorname{Var}\mathopen{}\left({\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} = 2\). Solution 4.

  1. The expected squared prediction error is the sum of the three sources: \(1 + 2 + 3 = 6\).

  2. \(0 + 0 + 3 = 3\). The noise variance \(\sigma^2= 3\) remains, so \(3\) is the smallest expected squared prediction error any prediction can have here.

ExrExercise 5 (Separate the noise)

Exercise 5 (Separate the noise) Let \(\mathopen{}\left(X_{*}, Y_{*}\right)\mathclose{}\) be a new observation relative to the random training set \(\mathcal{D}_{\text{train}}\). Fix \(X_{*}= x\). Let \(\nu\) be the noise of \(Y_{*}\). Let \(\sigma^2\stackrel{\text{def}}{=}\operatorname{Var}\mathopen{}\left(\nu\right)\mathclose{}\) be its population variance, which we take to be finite. Take every expectation below to be conditional on \(X_{*}= x\). Add and subtract \(\mu\mathopen{}\left(x\right)\mathclose{}\) inside the square of the expected prediction error,

\[ \operatorname{E}\mathopen{}\left[{\mathopen{}\left(Y_{*}- {\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}}^2\right]\mathclose{}, \]

expand it, and take the expectation term by term.

Two of the three terms simplify. Say what each becomes, and name which facts about the noise hold by definition and which hypothesis makes the cross term zero.

SolutionSolution 5

Solution 5. Write the prediction error as noise plus the error of the prediction, used as an estimator of the mean function value \(\mu\mathopen{}\left(x\right)\mathclose{}\):

\[ \begin{aligned} Y_{*}- {\hat y\mathopen{}\left(x\right)\mathclose{}} &= \mathopen{}\left(Y_{*}- \mu\mathopen{}\left(x\right)\mathclose{}\right)\mathclose{} + \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} && \text{(add and subtract } \mu\mathopen{}\left(x\right)\mathclose{} \text{)} \\ &= \nu+ \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} && \text{(definition of } Y_{*}\text{)} \end{aligned} \]

Square it:

\[ \begin{aligned} {\mathopen{}\left(Y_{*}- {\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}}^2 &= \nu^2 + 2 \nu\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} + {\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}}^2 && \text{(expand the square of a sum)} \end{aligned} \]

Take the expectation of each term in turn, using linearity of expectation to split the sum.

For the noise term, the variance identity gives \(\sigma^2= \operatorname{E}\mathopen{}\left[\nu^2\right]\mathclose{} - {\mathopen{}\left(\operatorname{E}\mathopen{}\left[\nu\right]\mathclose{}\right)\mathclose{}}^2\):

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[\nu^2\right]\mathclose{} &= \sigma^2+ {\mathopen{}\left(\operatorname{E}\mathopen{}\left[\nu\right]\mathclose{}\right)\mathclose{}}^2 && \text{(variance identity)} \\ &= \sigma^2+ 0^2 && \text{(the noise has population mean } 0 \text{)} \\ &= \sigma^2 && \text{(} 0^2 = 0 \text{, and } \sigma^2+ 0 = \sigma^2\text{)} \end{aligned} \]

For the cross term, \(\nu= Y_{*}- \mu\mathopen{}\left(x\right)\mathclose{}\) shifts \(Y_{*}\) by a constant, and \(Y_{*}\) is independent of \(\mathcal{D}_{\text{train}}\), so \(\nu\) is independent of \(\mathcal{D}_{\text{train}}\), and hence of \({\hat y\mathopen{}\left(x\right)\mathclose{}}\) and of \(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\). The expectation of a product of independent random variables is the product of their expectations:

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[2 \nu\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}\right]\mathclose{} &= 2 \operatorname{E}\mathopen{}\left[\nu\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}\right]\mathclose{} && \text{(constant factor 2)} \\ &= 2 \operatorname{E}\mathopen{}\left[\nu\right]\mathclose{} \operatorname{E}\mathopen{}\left[\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right]\mathclose{} && \text{(independence)} \\ &= 2 \cdot 0 \cdot \operatorname{E}\mathopen{}\left[\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right]\mathclose{} && \text{(the noise has population mean } 0 \text{)} \\ &= 0 && \text{(zero times a number)} \end{aligned} \]

Adding the three expectations,

\[ \operatorname{E}\mathopen{}\left[{\mathopen{}\left(Y_{*}- {\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}}^2\right]\mathclose{} = \sigma^2+ \operatorname{E}\mathopen{}\left[{\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}}^2\right]\mathclose{}. \tag{31}\]

The noise has population mean \(0\) by Theorem 1, so the algebra used only one hypothesis about the new observation: it is independent of the training set. Independence holds for a fresh observation, and it fails for an observation the procedure was trained on, whose noise helped determine the prediction. It also fails when the new observation depends on the training data (for example, a later time in the same series), or when the same test set was used to choose the procedure.

The algebra did not use that the new pair has the same population distribution as the training data. Suppose the new pair came from a population whose mean function differed from the training population’s. Then Equation 31 would still hold, with the new population’s mean function and noise variance. Its estimation-error term would include the bias from that difference. So it would no longer measure how well the procedure estimates the training population’s mean function.

Theorem 3 (The pMSE of a prediction is the pMSE of the mean estimate plus the noise variance) Let \(\mathopen{}\left(X_{*}, Y_{*}\right)\mathclose{}\) be a new observation relative to the random training set \(\mathcal{D}_{\text{train}}\). Fix \(X_{*}= x\). Let \(\nu\) be the noise of \(Y_{*}\). Let \(\sigma^2\stackrel{\text{def}}{=}\operatorname{Var}\mathopen{}\left(\nu\right)\mathclose{}\) be its population variance, which we take to be finite. Then, given \(X_{*}= x\), the expected squared prediction error (ESPE) of \({\hat y\mathopen{}\left(x\right)\mathclose{}}\) is the sum of two terms. The first is the irreducible error \(\sigma^2\). The second is the expected squared estimation error (ESEE) of \({\hat y\mathopen{}\left(x\right)\mathclose{}}\) as an estimator of \(\mu\mathopen{}\left(x\right)\mathclose{}\):

\[ \operatorname{ESPE}\mathopen{}\left({\hat y\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} = \sigma^2+ \operatorname{ESEE}\mathopen{}\left({\hat{\mu}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}. \tag{32}\]

Example 23 (The two pMSEs differ by the noise variance) Take a population whose mean function is known: \(Y\mid X= x\sim \operatorname{N}\mathopen{}\left(\sin(2 \pi x), \sigma^2\right)\mathclose{}\) with \(\sigma= 0.3\). split_sigma <- 0.3

split_draw <- function(n) {

  new_y <- split_truth(split_x0) + stats::rnorm(1, sd = split_sigma)

}) |>

The first term does not depend on \(\mathcal{D}_{\text{train}}\): \(\mu\mathopen{}\left(x\right)\mathclose{}\) is a constant, and \({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\) has already been averaged over training sets. The expectation of a constant is that constant:

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[{\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{}}^2\right]\mathclose{} &= {\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{}}^2 && \text{(expectation of a constant)} \\ &= {\mathopen{}\left({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- \mu\mathopen{}\left(x\right)\mathclose{}\right)\mathclose{}}^2 && \text{(a number and its negative have the same square)} \\ &= {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left(\hat{y}\right)\mathclose{}\right)\mathclose{}}^2 && \text{(definition of bias)} \end{aligned} \]

The cross term vanishes, and this time not by independence but because the expected prediction is the expectation of the prediction. The first factor is a constant, so it comes out of the expectation:

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \mathopen{}\left({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- \hat{y}\right)\mathclose{}\right]\mathclose{} &= 2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \operatorname{E}\mathopen{}\left[{\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- \hat{y}\right]\mathclose{} && \text{(constant factors)} \\ &= 2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \mathopen{}\left(\operatorname{E}\mathopen{}\left[{\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right]\mathclose{} - \operatorname{E}\mathopen{}\left[\hat{y}\right]\mathclose{}\right)\mathclose{} && \text{(linearity)} \\ &= 2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \mathopen{}\left({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- \operatorname{E}\mathopen{}\left[\hat{y}\right]\mathclose{}\right)\mathclose{} && \text{(expectation of a constant)} \\ &= 2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \mathopen{}\left({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} && \text{(definition of the expected prediction)} \\ &= 2 \mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{} \cdot 0 && \text{(} a - a = 0 \text{)} \\ &= 0 && \text{(a number times zero)} \end{aligned} \]

The third term is the expectation of the squared deviation of the prediction from its mean, which is the variance of the prediction:

\[ \begin{aligned} \operatorname{E}\mathopen{}\left[{\mathopen{}\left({\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}- \hat{y}\right)\mathclose{}}^2\right]\mathclose{} &= \operatorname{E}\mathopen{}\left[{\mathopen{}\left(\hat{y}- {\operatorname{E}_{\mathcal{D}_{\text{train}}}\mathopen{}\left[\hat{y}\right]\mathclose{}}\right)\mathclose{}}^2\right]\mathclose{} && \text{(a number and its negative have the same square)} \\ &= \operatorname{Var}\mathopen{}\left(\hat{y}\right)\mathclose{} && \text{(definition of variance)} \end{aligned} \]

Adding the three expectations,

\[ \operatorname{E}\mathopen{}\left[{\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - \hat{y}\right)\mathclose{}}^2\right]\mathclose{} = {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left(\hat{y}\right)\mathclose{}\right)\mathclose{}}^2 + \operatorname{Var}\mathopen{}\left(\hat{y}\right)\mathclose{}. \tag{33}\]

Neither cross term needed the noise to be normal, and neither assumed anything about the fitting procedure: \(g\) can be a line, a tree or a neural network. This split is specific to squared-error loss, the loss of this chapter’s examples.

LemTheorem 4 (Bias, variance and noise)

Theorem 4 (Bias, variance and noise) Let \(\mathopen{}\left(X_{*}, Y_{*}\right)\mathclose{}\) be a new observation relative to the random training set \(\mathcal{D}_{\text{train}}\). Fix \(X_{*}= x\). Let \(\nu\) be the noise of \(Y_{*}\). Let \(\sigma^2\stackrel{\text{def}}{=}\operatorname{Var}\mathopen{}\left(\nu\right)\mathclose{}\) be its population variance, which we take to be finite. Suppose also that \(\operatorname{E}\mathopen{}\left[{\mathopen{}\left(\hat{y}\right)\mathclose{}}^2\right]\mathclose{} < \infty\). Then the expected prediction error at \(x\) is the squared bias of the prediction \(\hat{y}\), used as an estimator of the mean function value \(\mu\mathopen{}\left(x\right)\mathclose{}\), plus its variance, plus \(\sigma^2\):

\[ \operatorname{EPE}^{g}_{n}\mathopen{}\left(x\right)\mathclose{} = {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left(\hat{y}\right)\mathclose{}\right)\mathclose{}}^2 + \operatorname{Var}\mathopen{}\left(\hat{y}\right)\mathclose{} + \sigma^2. \tag{34}\]

ProofProof

Proof. Every expectation below is conditional on \(X_{*}= x\), as in the exercises. By Solution 5, the expected squared prediction error is the noise variance plus the pMSE of the prediction, used as an estimator of \(\mu\mathopen{}\left(x\right)\mathclose{}\). By Solution 6, that pMSE is the squared bias plus the variance. Substituting Equation 33 into Equation 31:

\[ \begin{aligned} \operatorname{EPE}^{g}_{n}\mathopen{}\left(x\right)\mathclose{} &= \sigma^2+ \operatorname{E}\mathopen{}\left[{\mathopen{}\left(\mu\mathopen{}\left(x\right)\mathclose{} - \hat{y}\right)\mathclose{}}^2\right]\mathclose{} && \text{(separating the noise)} \\ &= \sigma^2+ {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left(\hat{y}\right)\mathclose{}\right)\mathclose{}}^2 + \operatorname{Var}\mathopen{}\left(\hat{y}\right)\mathclose{} && \text{(separating the bias)} \\ &= {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left(\hat{y}\right)\mathclose{}\right)\mathclose{}}^2 + \operatorname{Var}\mathopen{}\left(\hat{y}\right)\mathclose{} + \sigma^2 && \text{(reorder the terms)} \end{aligned} \]

DefDefinition 35 (Irreducible error)

Definition 35 (Irreducible error) In Theorem 4, the term \(\sigma^2= \operatorname{Var}\mathopen{}\left(\nu\right)\mathclose{}\) is the irreducible error. It does not depend on the fitting procedure \(g\), so no choice of prediction can remove it. The theorem concerns the single covariate value \(x\), so \(\sigma^2\) may differ from one covariate value to another: it does not assume constant noise variance across covariate values. For example, in Exercise 4, \(\sigma^2= 3\), so every prediction there has expected squared error at least \(3\).

Source: Wikipedia contributors [7].

RemarkRemark

Remark. This expected prediction error decomposition into squared bias, variance, and irreducible error follows James et al. [5, Sec. 2.2.2].

RemarkRemark 11 (Other names, and how the expected error splits)

Remark 11 (Other names, and how the expected error splits). Hastie et al. [3, Sec. 7.2] also call \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\) the test error, and in sec. 7.12 the conditional test error. It is the risk of the prediction \({\hat y\mathopen{}\left(X_{*}\right)\mathclose{}}\) under the loss \(L\), computed with the training set held fixed.

The argument \(n\) of the expected generalization error \(\operatorname{Err}^{g}\mathopen{}\left(n\right)\mathclose{}\) of a fitting procedure \(g\) records that it depends on how many observations each training set has. By Theorem 2, \(\operatorname{Err}^{g}\mathopen{}\left(n\right)\mathclose{}\) averages the expected prediction error at each covariate value, and Theorem 4 splits each of those expected prediction errors, under squared-error loss, into a squared bias, a variance and a noise variance.

DefDefinition 36 (Flexibility)

Definition 36 (Flexibility) Let \(g_{1}\) and \(g_{2}\) be fitting procedures that each choose, by least squares, a prediction rule from a set of candidate functions, \(\mathcal{G}_{1}\) and \(\mathcal{G}_{2}\) respectively. The procedure \(g_{2}\) is at least as flexible as \(g_{1}\) if every candidate of \(g_{1}\) is also a candidate of \(g_{2}\):

\[ \mathcal{G}_{1} \subseteq \mathcal{G}_{2}. \tag{35}\]

RemarkRemark 12 (Source: Flexibility)

Remark 12 (Source: Flexibility). James et al. [5, Sec. 2.1.3] use flexibility without a formal definition.

RemarkRemark 13 (Polynomial degree orders flexibility)

Remark 13 (Polynomial degree orders flexibility). Least-squares polynomial fits are ordered by degree: a polynomial of degree \(d\) is also a polynomial of degree \(d+ 1\) whose coefficient of \(x^{d+ 1}\) is zero, so the fit of degree \(d+ 1\) is at least as flexible as the fit of degree \(d\). The four fits of Exercise 1 are ordered this way. Definition 36 is narrower than the informal use of the word in James et al. [5, Sec. 2.1.3]: it orders only procedures whose candidate sets are nested. Other procedures can be compared by other measures, such as the effective number of parameters [3, Sec. 7.6].

DefDefinition 37 (Bias–variance trade-off)

Definition 37 (Bias–variance trade-off) Let \(g_{1}, \ldots, g_{L}\) be fitting procedures, each at least as flexible as the one before, and let \(\mathcal{D}_{\text{train}}\) be a random training set. At a covariate value \(x\), with \(\mu\) the mean function, there is a bias–variance trade-off among them when, from each procedure to the next, the squared bias of the prediction, used as an estimator of \(\mu\mathopen{}\left(x\right)\mathclose{}\), does not rise and its variance does not fall [7]:

\[ \begin{aligned} {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left({{\hat y_{l+ 1}}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}\right)\mathclose{}}^2 &\le {\mathopen{}\left(\operatorname{Bias}\mathopen{}\left({{\hat y_{l}}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}\right)\mathclose{}}^2, \\ \operatorname{Var}\mathopen{}\left({{\hat y_{l+ 1}}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{} &\ge \operatorname{Var}\mathopen{}\left({{\hat y_{l}}\mathopen{}\left(x\right)\mathclose{}}\right)\mathclose{}, \qquad l= 1, \ldots, L- 1. \end{aligned} \tag{36}\]

Source: James et al. [5, Sec. 2.2.2]; Wikipedia contributors [7].

RemarkRemark 14 (Overfitting and the trade-off)

Remark 14 (Overfitting and the trade-off). By Theorem 4, \(\operatorname{EPE}^{g_{l}}_{n}\mathopen{}\left(x\right)\mathclose{}\) is the squared bias plus the variance plus \(\sigma^2\). Under a bias–variance trade-off among \({\hat y_{1}}, \ldots, {\hat y_{L}}\), moving from \({\hat y_{l}}\) to \({\hat y_{l+ 1}}\) lowers the expected squared prediction error at \(x\) when the squared bias falls by more than the variance rises, and raises it otherwise. The smallest of \(\operatorname{EPE}^{g_{1}}_{n}\mathopen{}\left(x\right)\mathclose{}, \ldots, \operatorname{EPE}^{g_{L}}_{n}\mathopen{}\left(x\right)\mathclose{}\) is often at some \(g_{l}\) with \(1 < l< L\) [5, Sec. 2.2.2], but not always: if the mean function \(\mu\) is among the functions that candidate \(1\) can fit, the squared bias of \({\hat y_{1}}\) can be zero, and then no more flexible \({\hat y_{l}}\) has a smaller squared bias and, under the trade-off, none has a smaller variance, so none has a smaller expected squared prediction error. Past the candidate with the smallest expected squared prediction error, the more flexible candidates have lowered their squared bias by less than they have raised their variance, and their fitted models tend to overfit: they fit their training sets more closely than the fitted model of the candidate with the smallest expected squared prediction error but predict new observations worse.

RemarkRemark 15 (Coefficients per observation)

Remark 15 (Coefficients per observation). Adding coefficients to a least-squares fit makes it at least as flexible as before. With few observations per coefficient, the variance this adds can outweigh the squared bias it removes, which is the overfitting side of Remark 14. In Exercise 1, each added power of wt, like an added predictor, is one more coefficient fitted to the same 20 cars: the degree-4 fit has five coefficients for those 20 cars.

ExrExercise 7 (Held-out predictions and the generalization error)

Exercise 7 (Held-out predictions and the generalization error) A prediction rule \(\hat y\) is fitted to a training set \(\mathcal{D}_{\text{train}}\). A held-out set of \(m\) observations \((X_{*,1}, Y_{*,1}), \ldots, (X_{*,m}, Y_{*,m})\) is drawn from the same population as the new observation \((X_{*}, Y_{*})\) of Definition 19, each independently of \(\mathcal{D}_{\text{train}}\). Write \(\ell_{*,j}\) for the loss of \(\hat y\) on held-out observation \(j\).

Find, given \(\mathcal{D}_{\text{train}}\), the expected sample mean loss of the held-out predictions, in terms of the generalization error \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\):

\[ \operatorname{E}\mathopen{}\left[\frac{1}{m}\sum_{j=1}^{m} \ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{}. \]

SolutionSolution 7

Solution 7. Given \(\mathcal{D}_{\text{train}}\), the rule \(\hat y\) is fixed. Each held-out pair has the same distribution as \((X_{*}, Y_{*})\) and is independent of \(\mathcal{D}_{\text{train}}\), so each loss has conditional expectation \(\operatorname{E}\mathopen{}\left[\ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{} = \operatorname{Err}_{\mathcal{D}_{\text{train}}}\) by Equation 13. Then

\[ \begin{aligned} & \operatorname{E}\mathopen{}\left[\frac{1}{m}\sum_{j=1}^{m} \ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{} \\ &\quad = \frac{1}{m} \operatorname{E}\mathopen{}\left[\sum_{j=1}^{m} \ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{} && \text{(constant } 1/m\text{ out)} \\ &\quad = \frac{1}{m} \sum_{j=1}^{m} \operatorname{E}\mathopen{}\left[\ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{} && \text{(linearity of } \operatorname{E}\text{)} \\ &\quad = \frac{1}{m} \sum_{j=1}^{m} \operatorname{Err}_{\mathcal{D}_{\text{train}}} && \text{(each term, as above)} \\ &\quad = \frac{1}{m} \mathopen{}\left(m\, \operatorname{Err}_{\mathcal{D}_{\text{train}}}\right)\mathclose{} && \text{(} m\text{ equal terms)} \\ &\quad = \mathopen{}\left(\frac{1}{m} \cdot m\right)\mathclose{} \operatorname{Err}_{\mathcal{D}_{\text{train}}} && \text{(regroup the product)} \\ &\quad = 1 \cdot \operatorname{Err}_{\mathcal{D}_{\text{train}}} && (\tfrac{1}{m} \cdot m= 1) \\ &\quad = \operatorname{Err}_{\mathcal{D}_{\text{train}}} && \text{(multiplying by 1 changes nothing)} \end{aligned} \]

The step labeled “each term, as above” is the one that needs the held-out set to be independent of \(\mathcal{D}_{\text{train}}\).

LemTheorem 5 (The held-out sample mean loss estimates the generalization error)

Theorem 5 (The held-out sample mean loss estimates the generalization error) Let a prediction rule \(\hat y\) be fitted to a training set \(\mathcal{D}_{\text{train}}\), and let a held-out set of \(m\) observations \((X_{*,1}, Y_{*,1}), \ldots, (X_{*,m}, Y_{*,m})\) be drawn from the same population as \((X_{*}, Y_{*})\), each independently of \(\mathcal{D}_{\text{train}}\). Write \(\ell_{*,j}\) for the loss of \(\hat y\) on held-out observation \(j\). Then, given \(\mathcal{D}_{\text{train}}\), the expected sample mean loss of the held-out predictions is the generalization error:

\[ \operatorname{E}\mathopen{}\left[\frac{1}{m}\sum_{j=1}^{m} \ell_{*,j} \mid \mathcal{D}_{\text{train}}\right]\mathclose{} = \operatorname{Err}_{\mathcal{D}_{\text{train}}}. \]

ProofProof

Proof. This is Solution 7.

RemarkRemark 16 (Training error is optimistic)

Remark 16 (Training error is optimistic). The same argument fails for the training set. The training pairs are not independent of \(\mathcal{D}_{\text{train}}\): they are \(\mathcal{D}_{\text{train}}\), and \(\hat y\) was fitted to make their prediction errors small. So the argument of Theorem 5, that each loss has conditional expectation \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\), does not hold for them, and the training error \(\overline{\operatorname{err}}\) is typically smaller than \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\) [3, Sec. 7.4]. Exercise 1 shows the pattern: training sRMSE keeps falling as the degree grows, while held-out sRMSE does not.

DefDefinition 38 (Training/validation/test split)

Definition 38 (Training/validation/test split) A training/validation/test split divides the observations \(1, \ldots, n\) of a data set into three disjoint sets of indices, \(I_{\text{train}}\), \(I_{\text{val}}\) and \(I_{\text{test}}\), and takes the observations in \(I_{\text{train}}\) as the training set [2]:

\[ \begin{aligned} & I_{\text{train}}\cup I_{\text{val}}\cup I_{\text{test}}= \mathopen{}\left\{1, \ldots, n\right\}\mathclose{}, \\ & I_{\text{train}}\cap I_{\text{val}}= \emptyset, \\ & I_{\text{train}}\cap I_{\text{test}}= \emptyset, \\ & I_{\text{val}}\cap I_{\text{test}}= \emptyset, \\ & \mathcal{D}_{\text{train}}= \mathopen{}\left((x_{i}, y_{i})\right)\mathclose{}_{i\in I_{\text{train}}}. \end{aligned} \tag{37}\]

Source: James et al. [5, pp. 198–201]; Wikipedia contributors [2].

RemarkRemark 17 (What each set is for)

Remark 17 (What each set is for). Each set of a training/validation/test split has one job:

  • the training set is used to fit each candidate model, which estimates its parameters;
  • the validation set is used to compare the candidates, choose transformations, or choose values of a tuning parameter;
  • the test set is used once, after the validation choice is made, to estimate the generalization error of the chosen fitted model.

The chosen fitted model won on the validation set partly because of that particular validation sample, so its prediction error on the validation set is optimistic as an estimate of its generalization error. Keeping the test set out of every choice is what makes its score free of that optimism.

For further reading, the machine learning notes define the same three sets in their own notation: the training set, the validation set, and the test set. They use a different symbol for the training set and a parenthesized observation index, but the same three-way split.

RemarkRemark 18 (What the validation and test errors estimate)

Remark 18 (What the validation and test errors estimate). The validation error and the test error differ from the training error \(\overline{\operatorname{err}}\) only in the set that scores the rule. The rule was not fitted to the validation or test set, so each estimates the generalization error of the fitted rule without the optimism of the training error. The validation choice selects the rule with the smallest validation error, so the validation error of the chosen rule is still optimistic; the test error is computed once, after the choice, so it is not.

Hastie et al. [3, Sec. 7.2] use “test error” for the generalization error of the fitted rule itself. Here the test error is the number computed from the test set, and the generalization error is what it estimates.

Each definition holds for any loss. Under squared-error loss, they are sample mean squared errors; under absolute-error loss, they are sample mean absolute errors.

ExrExercise 9 (Folds of the mtcars data)

Exercise 9 (Folds of the mtcars data) Suppose we use \(k= 4\)-fold cross-validation on the \(n= 32\) cars in mtcars.

  1. How many cars are in each fold?
  2. Each time a model is fit, how many cars are used to fit it?
  3. How many models are fit in total?
  4. How many times is a given car used for fitting, and how many times for prediction?
SolutionSolution 9

Solution 9.

  1. \(32 / 4 = 8\) cars per fold.
  2. Each fit leaves out one fold, so it uses \(32 - 8 = 24\) cars.
  3. One model per fold, so \(4\) models.
  4. A given car is in exactly one fold. It is used for prediction once, when its fold is left out, and for fitting in the other \(3\) fits.
DefDefinition 46 (Folds)

Definition 46 (Folds) A division of a training set \(\mathcal{D}_{\text{train}}\), indexed by \(I\), into \(k\) folds is a partition of \(I\) into \(k\) nonempty, disjoint subsets \(\mathcal{F}_{1}, \ldots, \mathcal{F}_{k}\):

\[ \mathcal{F}_{1} \cup \cdots \cup \mathcal{F}_{k} = I. \tag{44}\]

RemarkRemark 19 (Source: Folds)

Remark 19 (Source: Folds). James et al. [5, Sec. 5.1.3] and Hastie et al. [3, Sec. 7.10.1], who split the data into \(k\) roughly equal-sized parts.

DefDefinition 47 (Fold size)

Definition 47 (Fold size) The size \(n_{j}\) of fold \(\mathcal{F}_{j}\) is the number of observations it contains:

\[ n_{j} \stackrel{\text{def}}{=}\mathopen{}\left|\mathcal{F}_{j}\right|\mathclose{}. \tag{45}\]

DefDefinition 48 (Fold assignment)

Definition 48 (Fold assignment) Given folds \(\mathcal{F}_{1}, \ldots, \mathcal{F}_{k}\), the fold assignment \(\kappa\mathopen{}\left(i\right)\mathclose{}\) of observation \(i\) is the index of the fold that contains it:

\[ i\in \mathcal{F}_{\kappa\mathopen{}\left(i\right)\mathclose{}}. \tag{46}\]

RemarkRemark 20 (Source: Fold assignment)

Remark 20 (Source: Fold assignment). The fold-assignment function \(\kappa\mathopen{}\left(i\right)\mathclose{}\) follows Hastie et al. [3, Sec. 7.10.1].

DefDefinition 49 (Fold-out rule)

Definition 49 (Fold-out rule) For fold \(\mathcal{F}_{j}\), the fold-out rule \(\hat y^{(-j)}\mathopen{}\left(\cdot\right)\mathclose{}\) is the prediction rule that a fitting procedure \(g\) produces from the observations outside that fold:

\[ \hat y^{(-j)}\mathopen{}\left(x\right)\mathclose{} \stackrel{\text{def}}{=}{{\hat y_{\mathopen{}\left((x_{i}, y_{i})\right)\mathclose{}_{i\in I\setminus \mathcal{F}_{j}}}}\mathopen{}\left(x\right)\mathclose{}}. \tag{47}\]

RemarkRemark 21 (Source: Fold-out rule)

Remark 21 (Source: Fold-out rule). Hastie et al. [3, Sec. 7.10.1], who write the fitted function with the \(k\)th part of the data removed as \(\hat f^{-k}\).

DefDefinition 50 (\(k\)-fold cross-validation)

Definition 50 (\(k\)-fold cross-validation) In \(k\)-fold cross-validation [10]:

  1. The data are randomly divided into \(k\) folds of equal, or nearly equal, size.
  2. For each fold \(\mathcal{F}_{j}\), \(j= 1, \ldots, k\):
    • Fit the model to all data except fold \(\mathcal{F}_{j}\), giving the fold-out rule \(\hat y^{(-j)}\mathopen{}\left(\cdot\right)\mathclose{}\).
    • Compute predicted values for the observations in fold \(\mathcal{F}_{j}\).
  3. Compute a summary prediction-error measure across all folds.

Source: Wikipedia contributors [10].

RemarkRemark 22 (Cross-validation instead of a single validation set)

Remark 22 (Cross-validation instead of a single validation set). If data are limited, \(k\)-fold cross-validation can replace the single validation set of Definition 38 for more stable tuning. In Exercise 9, \(k= 4\) folds of 8 cars each give 4 fits on 24 cars each.

DefDefinition 51 (Cross-validation estimate)

Definition 51 (Cross-validation estimate) The \(k\)-fold cross-validation estimate \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\) is the sMSE of the predictions that each observation \(i\in I\) of the training set receives from the fold-out rule of its fold assignment \(\kappa\mathopen{}\left(i\right)\mathclose{}\) in \(k\)-fold cross-validation:

\[ \widehat{\operatorname{Err}}_{\text{CV}(k)} \stackrel{\text{def}}{=}\frac{1}{n} \sum_{i\in I} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{48}\]

RemarkRemark 23 (Source: Cross-validation estimate)

Remark 23 (Source: Cross-validation estimate). Hastie et al. [3, Sec. 7.10.1], for the per-observation form with the fold index \(\kappa\mathopen{}\left(i\right)\mathclose{}\).

ExrExercise 10 (The cross-validation estimate, fold by fold)

Exercise 10 (The cross-validation estimate, fold by fold) Rewrite the cross-validation estimate Equation 48 as \(1/n\) times a double sum: an outer sum over the fold numbers \(j= 1, \ldots, k\) and an inner sum over the observations \(i\) in fold \(\mathcal{F}_{j}\). Then simplify the summand, so that it no longer uses the fold assignment \(\kappa\mathopen{}\left(i\right)\mathclose{}\).

SolutionSolution 10

Solution 10. The folds \(\mathcal{F}_{1}, \ldots, \mathcal{F}_{k}\) partition \(I\) (Definition 46), so summing over the observations of each fold and then over the folds adds each term of Equation 48 exactly once. For \(i\in \mathcal{F}_{j}\), Equation 46 also puts \(i\) in \(\mathcal{F}_{\kappa\mathopen{}\left(i\right)\mathclose{}}\), and the folds are disjoint, so \(\kappa\mathopen{}\left(i\right)\mathclose{} = j\). Then

\[ \begin{aligned} \widehat{\operatorname{Err}}_{\text{CV}(k)} &= \frac{1}{n} \sum_{i\in I} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2 && \text{(definition)} \\ &= \frac{1}{n} \sum_{j=1}^{k} \sum_{i\in \mathcal{F}_{j}} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2 && \text{(group by fold)} \\ &= \frac{1}{n} \sum_{j=1}^{k} \sum_{i\in \mathcal{F}_{j}} {\mathopen{}\left(\hat y^{(-j)}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2 && (\kappa\mathopen{}\left(i\right)\mathclose{} = j\text{ for } i\in \mathcal{F}_{j}) \end{aligned} \]

In the last line, the rule \(\hat y^{(-j)}\mathopen{}\left(\cdot\right)\mathclose{}\) depends only on the outer index, so each inner sum uses a single fitted rule.

LemTheorem 6 (The cross-validation estimate, fold by fold)

Theorem 6 (The cross-validation estimate, fold by fold) The cross-validation estimate sums, fold by fold, the squared errors of each fold’s observations under the rule fitted without that fold, and divides the total by \(n\):

\[ \widehat{\operatorname{Err}}_{\text{CV}(k)} = \frac{1}{n} \sum_{j=1}^{k} \sum_{i\in \mathcal{F}_{j}} {\mathopen{}\left(\hat y^{(-j)}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{49}\]

ProofProof

Proof. This is Solution 10.

DefDefinition 52 (Fold mean squared error)

Definition 52 (Fold mean squared error) The fold mean squared error \(\operatorname{MSE}_{j}\) of fold \(\mathcal{F}_{j}\) is the sMSE of the fold-out rule’s predictions for the \(n_{j}\) (fold size) observations in that fold:

\[ \operatorname{MSE}_{j} \stackrel{\text{def}}{=}\frac{1}{n_{j}} \sum_{i\in \mathcal{F}_{j}} {\mathopen{}\left(\hat y^{(-j)}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{50}\]

RemarkRemark 24 (Source: Fold mean squared error)

Remark 24 (Source: Fold mean squared error). James et al. [5, Sec. 5.1.3], who write the fold mean squared errors as \(\text{MSE}_1, \ldots, \text{MSE}_{k}\).

RemarkRemark 25 (What the cross-validation estimate estimates)

Remark 25 (What the cross-validation estimate estimates). Each prediction in Equation 48 comes from a rule that did not see the observation it predicts, so each squared error is scored as in Theorem 5. But the rule for fold \(\mathcal{F}_{j}\) was fitted to \(n- n_{j}\) observations, not \(n\), and the \(k\) rules differ from one another and from the rule fitted to all \(n\). So \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\) estimates the expected generalization error of the fitting procedure \(g\) at the smaller training-set sizes \(n- n_{j}\), which is \(\operatorname{Err}^{g}\mathopen{}\left(n(k- 1) / k\right)\mathclose{}\) when every fold has \(n/ k\) observations, rather than \(\operatorname{Err}_{\mathcal{D}_{\text{train}}}\) for the one rule fitted to all the data [3, Sec. 7.12].

When every fold has \(n_{j} = n/ k\) observations, \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\) is also the average of the \(k\) fold sMSEs \(\operatorname{MSE}_{1}, \ldots, \operatorname{MSE}_{k}\), the form James et al. [5, Sec. 5.1.3] use.

RemarkRemark 26 (Choosing the number of folds)

Remark 26 (Choosing the number of folds). The number of folds \(k\) trades bias against variance in the cross-validation estimate itself [5, Sec. 5.1.4]:

  • Bias. Each rule in Equation 48 is fitted to about \(n(k- 1) / k\) observations. A rule fitted to fewer observations usually predicts worse, so \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\) tends to overstate the expected generalization error of a rule fitted to all \(n\). The overstatement shrinks as \(k\) grows.
  • Variance. As \(k\) grows, the \(k\) training sets overlap more, so the \(k\) fitted rules are more alike and their errors are more strongly correlated. An average of strongly correlated errors varies more from one data set to another than an average of weakly correlated ones.
  • Computation. The model is fitted \(k\) times.

\(k= 5\) or \(k= 10\) is the usual compromise.

assign_folds <- function(n, k) {
  sample(rep_len(seq_len(k), n))
}

cv_squared_errors <- function(formula, data, folds) {
  y <- stats::model.response(stats::model.frame(formula, data))
  sq_errors <- numeric(nrow(data))
  for (j in unique(folds)) {
    in_fold <- folds == j
    fit <- lm(formula, data = data[!in_fold, ])
    pred <- predict(fit, newdata = data[in_fold, ])
    sq_errors[in_fold] <- (pred - y[in_fold])^2
  }
  sq_errors
}

cv_mse <- function(formula, data, folds) {
  mean(cv_squared_errors(formula, data, folds))
}

DefDefinition 53 (Leave-one-out cross-validation)

Definition 53 (Leave-one-out cross-validation) Leave-one-out cross-validation (LOOCV) is \(k\)-fold cross-validation with \(k= n\), so that each of the \(n\) folds holds one observation, and the fold-out rule \(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(\cdot\right)\mathclose{}\) of observation \(i\)’s fold is fitted to all observations except observation \(i\). Its cross-validation estimate (Equation 48 with \(k= n\)) is

\[ \widehat{\operatorname{Err}}_{\text{CV}(n)} = \frac{1}{n} \sum_{i\in I} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{51}\]

Source: James et al. [5, Sec. 5.1.2]; Wikipedia contributors [10].

LemLemma 1 (Leave-one-out cross-validation does not depend on the fold assignment)

Lemma 1 (Leave-one-out cross-validation does not depend on the fold assignment) Let \(\mathcal{D}_{\text{train}}= \mathopen{}\left((x_i, y_i)\right)\mathclose{}_{i \in I}\) be a training set of \(n = \mathopen{}\left|I\right|\mathclose{}\) observations, indexed by \(I\). Then the cross-validation estimate \(\widehat{\operatorname{Err}}_{\text{CV}(n)}\) of leave-one-out cross-validation (\(k = n\)) is the same for every fold assignment \(\kappa\mathopen{}\left(i\right)\mathclose{}\).

ProofProof

Proof. This is the solution to Exercise 11, part 3, worked in Solution 11. It uses Equation 48 and Equation 47.

Each step below changes one thing.

  1. With \(k = n\), the \(n\) nonempty, disjoint folds of Equation 44 partition the \(n\) indices of \(I\), so each fold holds exactly one index. (A partition of \(n\) indices into \(n\) nonempty, disjoint subsets has one index per subset.)

  2. For observation \(i\), Equation 46 gives \(i \in \mathcal{F}_{\kappa\mathopen{}\left(i\right)\mathclose{}}\), so \(\mathcal{F}_{\kappa\mathopen{}\left(i\right)\mathclose{}} = \mathopen{}\left\{i\right\}\mathclose{}\). (Fold \(\kappa\mathopen{}\left(i\right)\mathclose{}\) holds one index, and that index is \(i\).)

  3. Let \(g\) be the fitting procedure, the rule that maps a training set to a fitted prediction rule. The fold-out rule of observation \(i\) is then \(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x\right)\mathclose{} = {{\hat y_{\mathopen{}\left((x_{i'}, y_{i'})\right)\mathclose{}_{i' \in I \setminus \mathopen{}\left\{i\right\}\mathclose{}}}}\mathopen{}\left(x\right)\mathclose{}}\). (Equation 47 with \(\mathcal{F}_{\kappa\mathopen{}\left(i\right)\mathclose{}} = \mathopen{}\left\{i\right\}\mathclose{}\).)

  4. This rule is fitted to every observation except observation \(i\), and it does not involve \(\kappa\mathopen{}\left(i\right)\mathclose{}\) itself. (Step 3 depends on \(i\) and \(g\) only.)

  5. Hence each term \({\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_i\right)\mathclose{} - y_i\right)\mathclose{}}^2\) of Equation 48 is the same for every fold assignment. (Each term is a function of the rule in step 4, \(x_i\) and \(y_i\).)

  6. Therefore the sum over \(i \in I\) in Equation 48, and its factor \(1/n\), are the same for every fold assignment:

    \[ \widehat{\operatorname{Err}}_{\text{CV}(n)} = \frac{1}{n} \sum_{i \in I} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_i\right)\mathclose{} - y_i\right)\mathclose{}}^2. \]

    Different assignments give the same \(n\) fits, with the folds numbered differently.

DefDefinition 54 (Term vector)

Definition 54 (Term vector) Consider a model whose mean is a linear combination of \(p^{*}\) terms \(t_{1}(x), \ldots, t_{p^{*}}(x)\) of the covariate value, such as \(1\), \(x\) and \(x^2\). The term vector \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}\) of observation \(i\) is the column of its terms:

\[ \mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i} \stackrel{\text{def}}{=}{\mathopen{}\left(t_{1}(x_{i}), \ldots, t_{p^{*}}(x_{i})\right)\mathclose{}}^{\top}. \tag{52}\]

RemarkRemark 27 (The term vector of simple linear regression)

Remark 27 (The term vector of simple linear regression). In simple linear regression the terms are \(1\) and \(x\), so the term vector \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}\) is the covariate vector \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{x}}\vphantom{x}}_i\).

DefDefinition 55 (Cross-product matrix (sum-of-squares and cross-products matrix))

Definition 55 (Cross-product matrix (sum-of-squares and cross-products matrix)) The cross-product matrix \(A\) of term vectors \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}\), \(i\in I\), of a training set indexed by \(I\), is the sum of their outer products:

\[ A\stackrel{\text{def}}{=}\sum_{i\in I} \mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i} {\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}}^{\top}. \tag{53}\]

RemarkRemark 28 (Source: Cross-product matrix (sum-of-squares and cross-products matrix))

Remark 28 (Source: Cross-product matrix (sum-of-squares and cross-products matrix)). Also called a sum-of-squares and cross-products matrix [11], chap. “Matrix Cross-Products” (see the chapter online).

RemarkRemark 29 (Cross-product matrix as a matrix product)

Remark 29 (Cross-product matrix as a matrix product). Let \(D\) be the matrix whose rows are the transposed term vectors \({\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}}^{\top}\), \(i\in I\). The cross-product matrix then equals the matrix product

\[ A= {D}^{\top} D. \]

Its diagonal entries are sums of squares of one term over the training set. Its off-diagonal entries are sums of cross-products of two different terms. Statisticians therefore call \(A\) the sum-of-squares and cross-products (SSCP) matrix of the terms. When every column of \(D\) has mean zero, \(A/ (\mathopen{}\left|I\right|\mathclose{} - 1)\) is the sample covariance matrix of the terms.

DefDefinition 56 (Leverage)

Definition 56 (Leverage) Consider a linear model fitted by ordinary least squares, with term vectors \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}\), \(i\in I\), and an invertible cross-product matrix \(A\). The leverage of observation \(i\) is [12]

\[ h_{i} \stackrel{\text{def}}{=}{\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}}^{\top} A^{-1} \mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}. \tag{54}\]

Source: Wikipedia contributors [12].

RemarkRemark 30 (Source: Leverage)

Remark 30 (Source: Leverage). James et al. [5, Sec. 3.3.3], written here with term vectors and the matrix \(A\), as in the vector form of the OLS estimates.

LemTheorem 7 (Leave-one-out cross-validation for least squares)

Theorem 7 (Leave-one-out cross-validation for least squares) For a linear model fitted by ordinary least squares with every leverage \(h_{i} < 1\), the leave-one-out estimate can be computed from the single fit to all \(n\) observations, from its fitted values \(\hat y_{i}\), their prediction errors \(\varepsilon_{i} = \hat y_{i} - y_{i}\), and the leverages:

\[ \widehat{\operatorname{Err}}_{\text{CV}(n)} = \frac{1}{n} \sum_{i\in I} {\mathopen{}\left(\frac{\varepsilon_{i}}{1 - h_{i}}\right)\mathclose{}}^2. \tag{55}\]

ProofProof

Proof. Not derived here; see the sources named under the theorem. The derivation needs a formula for how the inverse of the cross-product matrix \(A\) changes when one observation’s outer product \(\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i} {\mathord{\smash[b]{\underset{\raise.3ex\hbox{$\scriptstyle\sim$}}{t}}\vphantom{t}}_{i}}^{\top}\) is removed from it (the Sherman–Morrison formula), which this page does not develop.

Remark 31 (Source: Leave-one-out cross-validation for least squares). James et al. [5, Sec. 5.1.2] states this formula for least squares linear or polynomial regression, and Hastie et al. [3, Sec. 7.10.1] for many linear fitting methods.

RemarkRemark 32 (When to use leave-one-out cross-validation)

Remark 32 (When to use leave-one-out cross-validation). LOOCV is the \(k= n\) end of Remark 26. By Remark 25, \(\widehat{\operatorname{Err}}_{\text{CV}(n)}\) estimates \(\operatorname{Err}^{g}\mathopen{}\left(n- 1\right)\mathclose{}\) for the fitting procedure \(g\): each rule is fitted to \(n- 1\) observations, so the bias of \(\widehat{\operatorname{Err}}_{\text{CV}(n)}\) as an estimate of \(\operatorname{Err}^{g}\mathopen{}\left(n\right)\mathclose{}\) is the smallest of any \(k\). But the \(n\) training sets are nearly identical, so the variance of \(\widehat{\operatorname{Err}}_{\text{CV}(n)}\) can be larger than that of 5- or 10-fold cross-validation [5, Sec. 5.1.4]. For least squares fits, Theorem 7 computes LOOCV from a single fit; for most other fitting methods, LOOCV requires \(n\) fits.

8 Choosing a model by cross-validation

DefDefinition 57 (Cross-validation estimate of a named procedure)

Definition 57 (Cross-validation estimate of a named procedure) Let a training set \(\mathcal{D}_{\text{train}}\), indexed by \(I\), be divided into folds \(\mathcal{F}_{1}, \ldots, \mathcal{F}_{k}\). The cross-validation estimate of procedure \(g\) on \(\mathcal{D}_{\text{train}}\), \({\widehat{\operatorname{Err}}^{g}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}\), is the cross-validation estimate computed with fold-out rules that \(g\) produces from \(\mathcal{D}_{\text{train}}\):

\[ {\widehat{\operatorname{Err}}^{g}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} \stackrel{\text{def}}{=}\frac{1}{n} \sum_{i\in I} {\mathopen{}\left(\hat y^{(-\kappa\mathopen{}\left(i\right)\mathclose{})}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{56}\]

DefDefinition 58 (Cross-validation choice procedure)

Definition 58 (Cross-validation choice procedure) Given candidate fitting procedures \(g_{1}, \ldots, g_{L}\), the cross-validation choice procedure \(g^{\text{CV}}\) is the fitting procedure that, applied to a training set \(\mathcal{D}_{\text{train}}\), divides \(\mathcal{D}_{\text{train}}\) into \(k\) folds, computes each candidate’s cross-validation estimate on \(\mathcal{D}_{\text{train}}\) with those folds, and applies to \(\mathcal{D}_{\text{train}}\) the candidate with the smallest estimate, taking the smallest \(l\) if several tie:

\[ {g^{\text{CV}}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} \stackrel{\text{def}}{=} {\hat y_{\min \arg \min_{l} {\widehat{\operatorname{Err}}^{g_{l}}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}}}. \tag{57}\]

ExmExample 32 (Inputs of the cross-validation choice procedure)

Example 32 (Inputs of the cross-validation choice procedure) The cross-validation choice procedure \(g\) over polynomials of several degrees is specified by these inputs:

  • model family \(\mathcal{H}\): the polynomials of every candidate degree;
  • objective function \(\mathcal{J}\): the residual sum of squares within each candidate, and the cross-validation estimate between candidates;
  • optimization algorithm \(\mathcal{A}\): the normal equations for each candidate, then keeping the candidate with the smallest cross-validation estimate of its expected generalization error \(\operatorname{Err}^{g_{d}}\mathopen{}\left(n\right)\mathclose{}\);
  • random seed \(\mathfrak{s}\): fixes the random fold assignment;
  • tuning parameter \(\lambda\): none, since cross-validation chooses the degree;
  • preprocessing \(\phi\): none.
DefDefinition 59 (Nested cross-validation)

Definition 59 (Nested cross-validation) Nested cross-validation is \(k\)-fold cross-validation of the cross-validation choice procedure \(g^{\text{CV}}\): its estimate on a training set \(\mathcal{D}_{\text{train}}\) is

\[ {\widehat{\operatorname{Err}}^{g^{\text{CV}}}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}. \tag{58}\]

RemarkRemark 33 (Source: Nested cross-validation)

Remark 33 (Source: Nested cross-validation). Hastie et al. [3, Sec. 7.10.2] for cross-validating every step of a procedure, choices included.

RemarkRemark 34 (What is nested)

Remark 34 (What is nested). Each fold-out rule of \(g^{\text{CV}}\) is computed from the observations outside one outer fold \(\mathcal{F}_{j}\), so the whole choice, including the cross-validation that \(g^{\text{CV}}\) runs inside those observations, never sees \(\mathcal{F}_{j}\). That inner cross-validation is the nested one.

RemarkRemark 35 (Cross-validation replaces the validation set, not the test set)

Remark 35 (Cross-validation replaces the validation set, not the test set). Used to choose between models, cross-validation takes the place of the validation set of Definition 38, the one consulted again and again, and not of the test set, which stays unused until the end. The cross-validation estimate of the winning model is optimistic: that model won partly because the particular sample and split happened to favor it, so its estimate is the smallest of several noisy estimates. An honest estimate of the chosen model’s error needs data that took no part in the choice [3, Sec. 7.2], such as a test set, or the outer folds of nested cross-validation.

NoteSource

Based on a Spring 2025 lecture on generalization by Logan Sizemore.

DefDefinition 60 (Fold-based standard error)

Definition 60 (Fold-based standard error) The fold-based standard error \(\operatorname{SE}_{\text{CV}(k)}\) of a \(k\)-fold cross-validation estimate is the sample standard deviation of the \(k\) fold sMSEs, divided by \(\sqrt{k}\):

\[ \operatorname{SE}_{\text{CV}(k)} \stackrel{\text{def}}{=}\frac{\mathop{\widehat{\operatorname{SD}}}\nolimits\mathopen{}\left(\operatorname{MSE}_{1}, \ldots, \operatorname{MSE}_{k}\right)\mathclose{}}{\sqrt{k}}. \tag{59}\]

RemarkRemark 36 (Source: Fold-based standard error)

Remark 36 (Source: Fold-based standard error). Hastie et al. [3, Sec. 7.10.1], who call the result a standard error.

RemarkRemark 37 (The fold-based standard error is only a rough guide)

Remark 37 (The fold-based standard error is only a rough guide). Hastie et al. [3, Sec. 7.10.1] draw standard-error bars computed from the per-fold errors as in Equation 59. That formula treats the \(k\) fold errors as if they were independent, which they are not: every pair of folds shares \(k- 2\) folds of training data. So \(\operatorname{SE}_{\text{CV}(k)}\) is a rough indication of how much \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\) might change with a different sample, not a standard error of \(\widehat{\operatorname{Err}}_{\text{CV}(k)}\).

DefDefinition 61 (Fold mean squared error of a named procedure)

Definition 61 (Fold mean squared error of a named procedure) The fold mean squared error of procedure \(g\) for fold \(\mathcal{F}_{j}\) of a training set \(\mathcal{D}_{\text{train}}\), indexed by \(I\), is the fold mean squared error computed with the fold-out rule that \(g\) produces:

\[ {\operatorname{MSE}^{g}_{j}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} \stackrel{\text{def}}{=}\frac{1}{n_{j}} \sum_{i\in \mathcal{F}_{j}} {\mathopen{}\left(\hat y^{(-j)}\mathopen{}\left(x_{i}\right)\mathclose{} - y_{i}\right)\mathclose{}}^2. \tag{60}\]

DefDefinition 62 (Fold-based standard error of a named procedure)

Definition 62 (Fold-based standard error of a named procedure) The fold-based standard error of procedure \(g\) on a training set \(\mathcal{D}_{\text{train}}\), \({\operatorname{SE}^{g}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}\), is the fold-based standard error computed from the fold sMSEs of \(g\):

\[ {\operatorname{SE}^{g}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} \stackrel{\text{def}}{=}\frac{\mathop{\widehat{\operatorname{SD}}}\nolimits\mathopen{}\left({\operatorname{MSE}^{g}_{1}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}, \ldots, {\operatorname{MSE}^{g}_{k}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}\right)\mathclose{}}{\sqrt{k}}. \tag{61}\]

DefDefinition 63 (One-standard-error rule)

Definition 63 (One-standard-error rule) Let \(g_{1}, \ldots, g_{L}\) be candidate fitting procedures, each at least as flexible as the one before, cross-validated on a training set \(\mathcal{D}_{\text{train}}\) with the same folds, and let \(g_{l^*}\) be the one with the smallest cross-validation estimate. The one-standard-error rule chooses the smallest \(l\) whose estimate is within one fold-based standard error of the smallest:

\[ {\widehat{\operatorname{Err}}^{g_{l}}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} \le {\widehat{\operatorname{Err}}^{g_{l^*}}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}} + {\operatorname{SE}^{g_{l^*}}_{\text{CV}(k)}\mathopen{}\left(\mathcal{D}_{\text{train}}\right)\mathclose{}}. \tag{62}\]

Source: [3, Sec. 7.10.1], [5, Sec. 6.1.3].

9 Cross-validating the whole procedure

ExrExercise 12 (Screening predictors before cross-validating)

Exercise 12 (Screening predictors before cross-validating) A data set has \(n= 50\) observations of an outcome \(Y\) and of \(p= 1000\) candidate predictors. In fact every variable is independent standard normal noise, so no predictor carries any information about \(Y\).

An analyst

  1. picks the 10 predictors most correlated with \(Y\) in all 50 observations, then
  2. estimates the prediction error of a linear model in those 10 predictors by 5-fold cross-validation.

Answer the following:

  1. What is the smallest possible generalization error (Equation 13) of any prediction rule for \(Y\) here?
  2. Simulate the analyst’s procedure. What cross-validation estimate does it report?
  3. Repeat the simulation, but carry out step 1 inside each fold, using only that fold’s training observations. What estimate does this give?
NoteSource

A regression version of the classification example in Hastie et al. [3, Sec. 7.10.2], “The Wrong and Right Way to Do Cross-validation”.

SolutionSolution 12

Solution 12.

  1. \(Y\) is independent of every predictor, with mean 0 and variance 1. The best prediction is the constant 0, and its generalization error is \(\operatorname{Var}\mathopen{}\left(Y\right)\mathclose{} = 1\). Every other rule does worse, so any honest estimate should be near or above 1.

  2. and 3. The function below runs one data set through both procedures. The only difference is whether the screening step sees the whole data set ("outside") or only the training folds ("inside").

top_predictors <- function(x, y, n_keep) {
  order(abs(stats::cor(x, y)), decreasing = TRUE)[seq_len(n_keep)]
}

screened_cv <- function(x, y, folds, n_keep, screen) {
  if (screen == "outside") {
    keep <- top_predictors(x, y, n_keep)
  }
  sq_errors <- numeric(length(y))
  for (j in unique(folds)) {
    in_fold <- folds == j
    if (screen == "inside") {
      keep <- top_predictors(x[!in_fold, ], y[!in_fold], n_keep)
    }
    train <- tibble::tibble(
      y = y[!in_fold],
      tibble::as_tibble(x[!in_fold, keep])
    )
    fit <- lm(y ~ ., data = train)
    held_out <- tibble::as_tibble(x[in_fold, keep])
    sq_errors[in_fold] <- (predict(fit, newdata = held_out) - y[in_fold])^2
  }
  mean(sq_errors)
}

RemarkRemark 38 (Cross-validate the whole procedure)

Remark 38 (Cross-validate the whole procedure). Every step that uses the outcome is part of fitting, and must be repeated inside each fold using only that fold’s training observations [3, Sec. 7.10.2]. Such steps include:

  • screening or selecting predictors, as in Exercise 12;
  • choosing transformations or a polynomial degree;
  • choosing a penalty or another tuning parameter.

Hastie et al. [3, Sec. 7.10.2] note that steps using only the predictors, such as dropping predictors with almost no variation, can be done once on all the data before the folds are formed. Repeating such a step inside each fold is never wrong, though, and it scores each held-out fold the way new data would be scored. Examples are estimating the mean and standard deviation used for standardization, and the values used to fill in missing predictor values, when they are computed without the outcome.
